# Identity and Memory System

## Purpose

Identity is a playable system, not only a story theme. The protagonist contains three interacting continuities:

- **Earthborn:** the person who lived before arriving in Avarra;
- **Vael:** the executed necromancer whose vessel, habits, relationships, and memory fragments remain;
- **Becoming:** the new identity created through the player's actions.

The system must support ambiguity without making state arbitrary.

## Identity state

Each continuity tracks:

- recognition by self;
- recognition by others;
- accessible memories;
- embodied habits;
- unresolved claims;
- Will strength;
- Name stability;
- active anchors;
- contradictions;
- accepted/rejected traits;
- current influence.

These are not three health bars. Most values are hidden and exposed through authored symptoms, discoveries, choices, and consequences.

## Identity pressure

Pressure changes through:

- origin-specific decisions;
- using Vael's instinctive skills;
- accepting or rejecting Vael's relationships;
- transferring into other vessels;
- memory loss or acquisition;
- public recognition under a Name;
- promises made and fulfilled;
- companion testimony;
- pact clauses;
- death and restoration;
- capstone transformations.

## Dominance and coexistence

Possible configurations include:

- Earthborn-dominant;
- Vael-restored;
- Becoming recognized as independent;
- negotiated coexistence;
- partial integration;
- unstable switching;
- distributed identity;
- mutual destruction;
- successor identity.

No configuration is a universal upgrade.

## Memory objects

A memory record contains:

- stable ID;
- claimed owner/source;
- subject and time;
- sensory/emotional fragments;
- confidence;
- integrity;
- accessibility;
- copy provenance;
- alterations;
- witnesses/corroboration;
- gameplay tags;
- privacy/consent claims;
- current anchors.

Memories are evidence, not guaranteed truth.

## Memory actions

Players may:

- witness;
- extract;
- preserve;
- copy;
- compare;
- suppress;
- share;
- implant;
- sacrifice;
- restore;
- return;
- destroy;
- use as ritual or skill evidence.

Every action records method and provenance.

## Earth memories

Earth memories ground Humanity and origin abilities. Important power may require risking an Earth memory, but loss must be specific and narratively reflected. The player is told the category and consequence before irreversible sacrifice without revealing hidden plot outcomes.

Examples:

- a loved one's face;
- professional knowledge;
- the sound of one's own language;
- reason for regretting the former life;
- original name.

## False and altered memories

A memory may be:

- accurate;
- incomplete;
- misinterpreted;
- rehearsed;
- copied;
- edited;
- composite;
- fabricated;
- created by bodily residue.

The engine stores canonical provenance while player-facing knowledge remains uncertainty-tagged.

## Mechanical integrations

Identity and memory affect:

- available dialogue;
- skill discoveries;
- vessel compatibility;
- relationship claims;
- spell resistance;
- legal identity;
- faction recognition;
- titles and legends;
- ending eligibility;
- New Game Plus Echoes.

## Safety and usability

- Never silently delete a major memory.
- Preview irreversible memory costs.
- Maintain a Chronicle of known losses and contradictions.
- Do not make players memorize hidden details to use information their character already knows.
- Offer reduced-intensity text variants for identity horror.

## Testing

Require deterministic tests for copying, merging, loss, restoration, conflicting ownership, vessel transfer, save migration, ending combinations, and hidden-information projections.
