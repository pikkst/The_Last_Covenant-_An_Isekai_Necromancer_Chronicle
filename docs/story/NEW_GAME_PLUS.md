# New Game Plus

## Goal

New Game Plus rewards narrative understanding and build experimentation without treating the first campaign as disposable or allowing the new character to know everything automatically.

## Unlock

Available after any complete non-corrupt ending. Hard failure endings may unlock limited Echo Mode after the first full completion.

## Carried forward

Player-level unlocks:

- Chronicle records;
- ending and route gallery;
- cosmetic themes;
- discovered glossary;
- optional advanced difficulty modifiers;
- origin variants;
- build templates;
- challenge seeds.

Character-level carryover is limited and selected:

- one Soul Scar;
- one non-capstone technique as an Echo;
- one remembered relationship impression;
- one relic memory without the physical relic;
- one question the new protagonist can ask earlier.

## Not carried forward

- ordinary inventory/currency;
- territory;
- faction reputation;
- quest flags;
- complete NPC knowledge;
- armies;
- covenant authority;
- unrestricted capstones.

## Echo system

Past campaigns appear as ambiguous echoes:

- dreams;
- déjà vu;
- alternate body memories;
- optional challenge encounters;
- rare dialogue alternatives;
- warnings that may be incomplete.

Echoes never silently overwrite current continuity.

## New content

New Game Plus may unlock:

- Vael-focused origin;
- rejected claimant routes;
- additional Second Voice interpretations;
- earlier access to difficult hybrid builds;
- covenant clauses requiring knowledge from multiple completions;
- challenge bosses;
- companion perspective interludes.

Core endings remain reachable on the first campaign.

## Difficulty

Optional modifiers:

- severe resource scarcity;
- permanent named-undead destruction;
- hidden check information;
- accelerated world clocks;
- stronger ideological companion boundaries;
- iron covenant checkpoint rules.

Accessibility settings remain independent.

## Save model

Each campaign has its own save. Account-level Chronicle stores completion unlocks separately with provenance. Import/export validates both layers. Deleting a campaign does not silently delete account-level unlocks unless explicitly requested.

## Integrity

New Game Plus bonuses are server validated and content-versioned. A build cannot equip incompatible Echo skills. Golden replay tests cover each carryover category.
